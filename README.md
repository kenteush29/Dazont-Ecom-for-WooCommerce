# Dazont Ecom pour WooCommerce

Une boîte à outils pour boutiques WooCommerce, faite de modules qu'on allume un par un :

- réassort ;
- fiches produits, catégories et photos préparées par IA ;
- traductions WPML ;
- remises et promotions ;
- e-mails Klaviyo ;
- Google Merchant Center et Google Ads ;
- maillage interne et netlinking.

## Installer

1. Télécharger la dernière version : **[dazont-ecom.zip](https://github.com/kenteush29/Dazont-Ecom-for-WooCommerce/releases/latest/download/dazont-ecom.zip)**
2. Dans WordPress : **Extensions → Ajouter → Téléverser une extension**. Choisir le fichier, installer, puis **Activer**.
3. **Dazont Ecom → Settings → Modules** : n'allumer que les modules dont la boutique a besoin.
4. **Dazont Ecom → Setup** : cette page liste ce qu'il reste à régler (clés, connexions), avec les liens pour le faire.

Il faut WordPress 6.0 ou plus récent, PHP 8.0 ou plus récent, et WooCommerce.

## Mises à jour

L'extension se met à jour seule à partir des versions publiées ici, comme une extension WordPress ordinaire.

## Clés et coûts

Les modules qui passent par un service extérieur utilisent les clés de la boutique. Chaque appel est facturé sur le compte de la boutique :

- Anthropic : rédaction et traduction ;
- fal.ai : images ;
- Klaviyo : e-mails ;
- Google : un seul compte de service pour Merchant Center, Google Ads et Search Console.

L'interface de l'extension est en anglais.
